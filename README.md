# ErsVisa – Sitio Web Institucional

Sitio web oficial de ErsVisa, S.R.L., desarrollado y mantenido como parte de mis funciones como Técnico Informático en la empresa. El sitio presenta los servicios de la compañía y facilita el contacto con clientes.

## Descripción

Página web informativa que representa la presencia digital actual de ErsVisa. Desarrollada con un enfoque en claridad de información y facilidad de contacto para los usuarios.

## Tecnologías utilizadas

- *HTML5* – Estructura semántica
- *CSS3* – Estilos y diseño visual
- *JavaScript* – Interactividad de la interfaz

## Estructura del proyecto

```
ErsVisa/
├── Css/          # Hojas de estilo
├── Img/          # Recursos gráficos
├── Js/           # Scripts de interactividad
├── Sections/     # Secciones modulares del sitio
└── index.html    # Página principal
```

## Características

- Sitio actualmente en producción para uso real de la empresa
- Diseño responsivo
- Integración de enlace directo a WhatsApp para atención al cliente
- Estructura modular por secciones
